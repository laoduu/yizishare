核心功能

聊天与共享，一套应用全包了

把「发消息」和「传文件」揉进同一个窗口，再顺手把共享文件夹也搬进来——局域网协作不必再来回切换工具。

自动发现同网段设备

UDP 广播心跳 + 定向单播兜底（穿透防火墙对入站的拦截），叠加 ARP 缓存 / ICMP Ping / TCP 端口三路并发探测，覆盖主机位全段。打开就在线，不用填 IP。

消息类型齐全

文字、Twemoji 彩色表情（200+，消息内彩色渲染）、气泡内图片直显、文件卡片，一应俱全。截图或文件复制后直接粘贴进输入框即可发送。

离线补发

对方不在线也能先发出去：消息进入本地队列等待重投，设备重新上线后自动补发，不需要你重发一遍。

送达与已读回执

投递状态实时流转，谁收到了、谁还没看一目了然。消息状态按会话隔离，不跨会话串扰。

昵称三层优先级

显示名按「好友备注 > 对方自报昵称 > 主机名」取值；在设置里改一次「我的昵称」，数秒内同步到所有对端。

未读角标与提示音

未读红点叠在设备头像右上角，新消息同时触发提示音与右下角横幅，不占用系统通知气泡。

设备 + 共享三合一扫描

ARP 缓存、ICMP Ping、TCP 端口三路并发探测定位主机，再叠加 NetShareEnum 结构化枚举，一次把共享列表列全，并自动过滤电视家电等无共享设备。

SMB 智能诊断

连接失败不再只有一句「无法访问」。通过 IPC$ 探测获取 Win32 真实错误码，区分来宾访问被策略阻止、凭据冲突、端口未开、仅支持 SMB1 等情形。

一键提权修复

本机可修的问题一键修复并自动复检；需要账号的设备直接在应用内输入凭据连接，密码仅内存传递、不落盘。目标侧问题给出分步中文指引。

共享文件夹内置浏览

列表 / 图标双视图，列头为名称、大小、修改时间。右键菜单与 Ctrl+C / X / V、F2、Delete 快捷键齐备，像操作本机一样翻对方的共享盘。

拖放上传下载

直接把文件拖进窗口即上传，下载到本地一步到位，按类型显示系统文件图标，粘贴冲突时会询问覆盖 / 跳过 / 取消。

大文件流式传输

控制与数据通道分离：聊天帧只带文件提议，接收方确认后回拨同端口建立数据连接，走原始二进制流——无 base64 膨胀、无分块、无大小上限。

接收方确认制

对方确认接收后才建立数据连接，配合磁盘空间预检，防止他人向你的机器传输轰炸、占满硬盘。

传输状态全程可见

收发双向进度条 + 内联取消按钮。等待对方接收 / 传输中 / 已送达 / 对方拒绝接收 / 已拒绝接收 / 已取消传送 / 对方已取消传送 / 超过 5 分钟未接收，状态语义逐阶段分离。

通知横幅

微信式右下角横幅，带发送者与消息预览，点击直达对应会话；新消息同时触发提示音，不打断手上的工作。

黑金主题 · 明暗双态

取色自应用图标的黑金体系（品牌金 #C8912A + 暖黑 #1C1913），标题栏一键切换明暗，偏好自动持久化。

网络唤醒（WoL）

对离线且有 MAC 的设备直接发送 Wake-on-LAN 魔术包把它叫醒，远程开机后再接着传文件。

多网卡智能识别

以「已启用网卡 + IPv4 网关」定位本机子网，排除虚拟网卡与多网卡环境的干扰，扫描范围不再跑偏。

工作原理

没有服务器，只有两台电脑在说话

用 UDP 广播互相「打招呼」，用 TCP 建立可靠连接，文件走独立数据通道。所有数据点对点流动，中间没有任何中转节点。

你的电脑 UDP 45455 · TCP 45402
局域网 · 点对点直连 广播心跳 聊天帧 / 文件提议 数据流 · 二进制
对端设备 NAS / 笔记本 / 台式机
  1. 1
    广播发现

    UDP 45455 收发合一 socket 发出广播心跳，源端口固定使双方端点对称，出站会话的回包必然命中；对已知对端再用定向单播兜底，穿透防火墙对入站的拦截。

  2. 2
    建立会话

    握手成功后建立 TCP 45402 控制通道，首帧声明本次连接用途（Hello 或 FileData 分派），控制与数据各走各的通道。

  3. 3
    传输数据

    聊天帧只携带文件提议；接收方确认并完成磁盘空间预检后，回拨同端口建立数据连接，文件以原始二进制流传输。

  4. 4
    离线兜底

    对端不在线时消息进入本地队列，设备重新上线后自动补发，并同步送达与已读状态。

数据不出内网

不依赖任何云端服务，不上传设备信息与文件内容。设备身份（NodeId）与昵称仅保存在本机 %LocalAppData%\YiziShare，并在 Roaming 目录留有备份用于重装后恢复身份。凭据仅在内存中传递，不落盘。

使用指南

三步开始，比装个输入法还快

绿色便携版解压即用，不需要安装、不需要注册账号，两台在同一网段的电脑就能立刻聊起来。

STEP 1

下载并解压

从 Releases 下载 YiziShare-v0.9.36-x64.zip，解压到任意目录，双击 YiziShare.App.exe 即可运行。自包含发布，无需预装 .NET 运行时。

STEP 2

扫描同网段设备

点标题栏的重新扫描，应用会自动列出同网段设备与它们开放的共享文件夹。连接失败时，设备详情里的诊断卡会说明原因并给出修复入口。

STEP 3

在聊天与共享之间切换

选中设备即可开始聊天；点右侧的「共享」标签查看对方共享，点「打开」进入内置浏览。把文件拖进窗口就是传输，三种需求一个窗口搞定。

开发者：项目基于 .NET 8 + WPF，克隆仓库后执行 dotnet build YiziShare.sln 编译；dotnet test 可运行全量 172 个单元测试。

常见问题

你可能想知道

需要安装服务器或者联网吗？

都不需要。YiziShare 是纯客户端应用，所有发现、聊天与传输都发生在局域网内，不依赖公网、不依赖任何云端账号体系。

传文件有大小上限吗？

没有。v0.9.36 起采用控制与数据通道分离的流式传输：聊天帧只携带文件提议，接收方确认后回拨同端口建立数据连接，文件以原始二进制流传输，不做 base64 编码、不做分块、不设大小上限。传输前还会做磁盘空间预检。

能跨网段 / 跨路由使用吗？

默认面向同一网段。UDP 广播不会跨越路由器，但应用同时提供定向单播兜底与 ARP / Ping / 端口扫描，在路由允许的前提下可覆盖部分跨网段场景；完整跨网段组网建议配合静态路由或 VPN。

提示「无法访问共享文件夹」怎么办？

点开设备详情会看到诊断卡：本机可修的问题（来宾访问被策略阻止、凭据冲突、网络发现关闭等）可以直接一键提权修复并自动复检；需要账号的设备会弹出凭据对话框，密码仅内存传递、不落盘。

支持 macOS / Linux 吗？

目前基于 WPF 构建，仅支持 Windows 10 / 11（自包含发布，无需预装 .NET 运行时）。核心通信逻辑集中在 YiziShare.Core 中与界面解耦，便于后续移植。

可以商用吗？

可以。项目以 MIT 协议开源，可自由使用、修改与分发，保留版权声明即可。
