## 📖 简介

**YiziShare** 是一款仿QQ风格的局域网共享文件夹助手，帮助你快速发现和访问局域网中所有设备的共享文件夹。支持智能SMB诊断与一键修复、设备昵称备注、黑金主题与明暗切换、系统托盘常驻，界面采用无边框液态玻璃设计，精致美观。

---

## ✨ 主要功能

### 🔍 智能扫描
- **ARP缓存读取** - 快速获取已知设备
- **ICMP Ping扫描** - 并发探测活跃设备（全段覆盖 `.1~.254`）
- **TCP端口扫描** - 检测SMB 445端口
- **自动过滤** - 只显示有共享文件夹的设备（过滤电视、打印机等）
- **网卡智能识别** - 通过网关自动选择物理网卡所在子网（排除 Hyper-V/WSL 虚拟网卡）
- **设备厂商识别** - 根据MAC地址OUI前缀识别设备品牌（约45个厂商）

### 📂 共享管理
- **自动发现** - 枚举设备上的所有共享文件夹
- **快速访问** - 点击"打开"按钮或双击卡片打开资源管理器
- **全部打开** - 一键打开选中设备的所有共享
- **路径显示** - 清晰显示UNC共享路径

### 🩺 智能SMB诊断与一键修复
- **自动诊断** - 扫描即检测每台设备的SMB连接，识别 10+ 种问题（端口关闭、登录失败、密码保护、来宾访问被阻止、凭据冲突、防火墙拦截、公共网络、SMB1-only 等）
- **三种一键解决闭环**：
  - 🛠 **本机可修**（来宾访问被阻止/凭据冲突/网络路径不通/网络发现关闭）→ UAC 提权自动执行 → 自动复检转绿
  - 🔑 **需要登录** → 应用内凭据对话框输入账号密码，直连后直接刷出共享（密码仅内存传递）
  - 📋 **目标侧问题** → 分步中文指引 + 复制全部指引 + 「我修好了，重新检测」
- **Win32 级诊断** - 通过 IPC$ 连接探测获取真实错误码，精准定位问题
- **中文解决方案** - 针对每种问题提供详细的中文修复步骤

### 💬 QQ风格界面
- **无边框圆角窗口** - 黑金渐变标题栏（取色自应用图标），液态玻璃设计
- **可折叠面板** - 默认只显示设备列表（窄条），点击设备展开详情；收起按钮位于标题栏扫描键旁
- **明暗主题切换** - 标题栏 🌙/☀️ 一键切换，偏好自动保存
- **设备昵称** - 支持给设备起别名，持久化保存
- **搜索过滤** - 实时搜索设备名称/IP/昵称
- **设备卡右键菜单** - 打开全部共享 / 重新检测 / 修改昵称
- **系统托盘** - 最小化到托盘，双击恢复，右键菜单

### 🖼️ 设备图标识别
根据MAC地址自动识别设备类型并显示对应图标：
- 🍓 Raspberry Pi
- 🖥️ VMware/VirtualBox
- 🍎 Apple设备
- 🖨️ HP设备
- 📡 TP-Link/Tenda路由器
- 💻 其他设备

## 🚀 快速开始

### 环境要求
- Windows 10/11
- .NET 8.0 SDK（编译）
- 或无运行环境需求（绿色便携版）

### 编译运行

```bash
# 编译
dotnet build

# 运行
dotnet run --project YiziShare.App
```

### 发布绿色便携版

```bash
# 发布完全自包含版（无需安装.NET，绿色便携）
dotnet publish YiziShare.App -c Release -o publish -p:PublishSingleFile=true -p:SelfContained=true -r win-x64

# 或发布依赖框架的小体积版（目标机需安装 .NET 8 运行时）
dotnet publish YiziShare.App -c Release -o publish -p:PublishSingleFile=true -p:SelfContained=false
```

> `publish/` 为唯一绿色发布目录，整个文件夹拷贝即可运行（含 Assets 图标资源）。

### 单元测试

```bash
dotnet test YiziShare.Tests
```

## 📝 使用指南

1. **启动程序** - 自动扫描局域网，发现所有有共享的设备
2. **查看设备** - 左侧列表显示设备卡片（名称、IP、共享数量/状态）
3. **搜索过滤** - 在搜索框输入关键词快速定位设备
4. **修改昵称** - 点击设备上的 ✏️ 按钮，输入自定义昵称
5. **查看共享** - 点击设备展开右侧详情面板
6. **打开文件夹** - 点击共享卡片的"打开"按钮，或双击卡片
7. **全部打开** - 点击设备详情顶部的"全部打开"按钮
8. **处理连接问题** - 设备显示 ⚠️ 时点击进入详情，按修复卡操作：
   - 🛠 一键修复：点按钮 → 确认风险 → UAC 授权 → 自动复检
   - 🔑 需要登录：输入目标设备账号密码直连
   - 📋 目标侧问题：按指引在目标设备操作 → 点「我修好了，重新检测」
9. **切换明暗主题** - 点击标题栏扫描键右侧的 🌙/☀️ 按钮，偏好自动保存
10. **收起详情面板** - 点击标题栏扫描键左侧的 ◀ 按钮
11. **最小化到托盘** - 点击标题栏 ─ 按钮，或直接关闭窗口
12. **恢复窗口** - 双击托盘图标，或右键选择"打开YiziShare"
13. **彻底退出** - 右键托盘图标 → 退出

## 🔧 技术实现

### 扫描原理
| 阶段 | 方法 | 速度 | 准确度 |
|------|------|------|--------|
| 1 | ARP缓存读取 (`arp -a`) | 极快 | 高 |
| 2 | ICMP Ping并发扫描 | 快 | 中 |
| 3 | TCP 445端口扫描 | 中等 | 最高 |

### SMB诊断流程
1. 检测TCP 445端口是否开放；未开放则检测139端口（区分"仅NetBIOS"与"端口不通"）
2. 445开放后通过 `WNetAddConnection2` 探测 `\\ip\IPC$`，获取真实 Win32 错误码
3. 错误码映射到具体问题类型（登录失败/密码错误/凭据冲突/来宾访问被阻止/访问拒绝/网络路径不通…）
4. 按问题类型生成针对性修复方案（本机一键修复 / 凭据直连 / 目标侧指引）
5. 共享枚举使用 `NetShareEnum` 结构化获取，`net view` 修正后兜底

### 界面设计
- **无边框** - `WindowStyle=None` + `AllowsTransparency=True`
- **圆角** - 主容器 CornerRadius=16，底层阴影 + 主题细边
- **黑金渐变** - 标题栏/状态栏黑金渐变（取色自应用图标），金色高光与分隔线
- **明暗主题** - 品牌层共用，表面层双字典运行时热切换
- **液态玻璃** - 半透明悬停效果，柔和阴影
- **QQ风格** - 默认窄条列表，点设备展开详情
